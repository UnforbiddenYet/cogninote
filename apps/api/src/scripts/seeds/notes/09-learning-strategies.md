# How I Learn New Things

Strategies that help me learn effectively.

## The Process

1. **Survey** - Skim the material, get the big picture
2. **Learn** - Go through content actively
3. **Practice** - Apply immediately
4. **Teach** - Explain to someone (or write notes)

## Active vs Passive

**Passive (avoid):** Watching tutorials, re-reading

**Active (prefer):** Building projects, writing summaries, solving problems

## Spacing Effect

Don't cram. Spread learning over time:
- Day 1: Learn
- Day 2: Review
- Day 7: Review
- Day 30: Review

## For Technical Skills

1. Find a real project to build
2. Learn just enough to start
3. Get stuck, search for solutions
4. Document what you learn
5. Repeat

## Key Insights

- Confusion is part of learning
- Mistakes accelerate progress
- Teaching others solidifies knowledge
- Small daily practice beats weekend binges

The goal isn't to learn faster, but to retain more of what you learn.
