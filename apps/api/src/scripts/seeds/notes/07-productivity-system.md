# My Productivity System

A simple system that actually works for me.

## Core Principles

1. **Capture everything** - Get it out of your head
2. **Weekly review** - Process and prioritize
3. **Daily top 3** - Focus on what matters
4. **Time blocking** - Protect deep work

## Tools I Use

- **Notes:** Personal knowledge base
- **Tasks:** Simple todo list
- **Calendar:** Time blocking
- **Focus:** Pomodoro timer

## Daily Routine

**Morning:** Review calendar, set top 3 priorities
**Work blocks:** 90 min focused, 15 min break
**End of day:** Clear inbox, plan tomorrow

## Weekly Review (Sunday, 1 hour)

1. Process all inboxes
2. Review completed tasks
3. Update project lists
4. Plan next week's priorities

## What I Stopped Doing

- Complex productivity apps
- Multiple todo lists
- Tracking everything
- Guilt over unfinished tasks

Simple beats sophisticated. The best system is one you'll actually use.
